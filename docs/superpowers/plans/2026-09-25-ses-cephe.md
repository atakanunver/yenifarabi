## Uç noktalar

- `GET /v1/models` → `{"object":"list","data":[{"id":"farabi-brain","object":"model","owned_by":"farabi"}]}`
- `POST /v1/chat/completions` — gövde OpenAI biçimi: `model`, `messages`,
  `stream` (varsayılan false), `metadata` (opsiyonel: `kip`, `ders`,
  `derslik`). Gelen `tools`/`tool_choice` ve `system` mesajları YOK SAYILIR —
  persona ve araçlar Brain'in (API Prensibi: Brain karar verir).

## Erişim (router dependency'leri, üç katman)

1. **Adres:** `request.client.host` ∈ `FARABI_SES_IZINLI` (virgüllü; varsayılan
   `127.0.0.1,::1`) değilse 403.
2. **Bearer:** `Authorization: Bearer <FARABI_SES_TOKEN>`; `hmac.compare_digest`.
   Env değişkeni tanımsız/boşsa 503 `"ses cephesi yapılandırılmamış"`
   (fail-closed). Token loglanmaz.
3. **Tahta:** mevcut `auth.dogrula_tahta` (`X-Farabi-Board-Key`). Derslik
   dönen `TahtaKimligi.derslik`'ten — gövdedeki `metadata.derslik` kimlik
   olarak KULLANILMAZ. İstisna: `dogrula_tahta` None döndüyse
   (`FARABI_AUTH_REQUIRED=0` acil rollback modu) `metadata.derslik` kullanılır.
   Sınıf düzeyi derslikten: `re.match(r"^(\d{1,2})", derslik)` (client
   `core/tahta.py::sinif_duzeyi` ile aynı; `fenlab` → None).

## Persona ve araçlar

`ses_persona.txt` ≤ ~1800 karakter. İçerik: Farabi kimliği (Türkçe, kısa
konuşma cümleleri — ses için, madde işareti/markdown yok); bilgi/tanım/
neden-nasıl sorusunu ASLA kendi bilgisiyle cevaplamama → `kitap_sorusu`;
konu anlatımı → `ders_icerigi`; sayfa göster → `pdf_sayfa`; çıkmış soru →
`yks_sorulari` (soruyu ve şıkları oku, sonra sus, çözümü hemen anlatma);
selam/teşekkür/kısa sohbet → araçsız tek cümle. Üç kip bölümü
(`client/main.py:800-822` ve `KIP_TALIMAT` açıklamasından özetlenir):
`ogretmenli` (öğretmene "kıymetli öğretmenim", sınıfa "çocuklar"; öğretmen
söz alınca sus), `ogretmensiz` (akış ve doğruluk Farabi'de), `talimat` (ders
yok; tek cümlelik komutları uygula, "Açılıyor." gibi çok kısa onay).
Sistem mesajına ayrıca eklenir: `Derslik: {derslik}`, `Sınıf düzeyi: {n}`,
`Şu anki ders: {metadata.ders}` (varsa), tarih-saat (24 saat biçimi).

Araç şemaları — **parametre adları client'taki `actions/kayit.py` ile BİREBİR
aynı** (tahta araçları mevcut client eylemleriyle çalıştırılacak). Açıklamalar
Türkçe ve kısa. Kip filtresi `kayit.py` ile aynı:

| Araç | Nerede çalışır | Kipler | Parametreler |
|---|---|---|---|
| `kitap_sorusu` | sunucu | hepsi | `soru` (zorunlu), `ders`, `sinif` |
| `ders_icerigi` | sunucu | ogretmenli, ogretmensiz | `konu`, `ders`, `sinif`, `tema`, `sayfa_adedi` |
| `pdf_sayfa` | tahta | hepsi | `sayfa` (zorunlu), `ders`, `sinif` |
| `yks_sorulari` | tahta | hepsi | `konu`, `ders`, `adet`, `sonraki` |
| `pencere_kapat` | tahta | yalnızca talimat | `hedef` (zorunlu) |

`yks_sorulari` bilerek tahta aracı: client'taki `actions/yks_sorulari.py`
sunucu çağrısını + sayfa görüntüsünü zaten yapıyor, `_OTURUMLAR` derslik
anahtarı korunuyor; cephede yeni kod gerekmiyor.

## Ajan döngüsü (`POST /v1/chat/completions`)

1. Mesajları OpenAI → Ollama native (`/api/chat`) biçimine çevir:
   `assistant.tool_calls[].function.arguments` JSON string → dict; `tool`
   rolü mesajlar `content` ile aynen. Gelen system mesajlarını at, persona
   sistem mesajını başa koy.
2. **Bağlam bütçesi** (Ollama bağlamı 8192): token tahmini = karakter / 2.7
   (Faz 0 ölçümü: 36 061 karakter → 13 403 token). Geçmiş (system hariç)
   en yeniden geriye ≤ 2000 token olacak şekilde kırpılır; son kullanıcı
   mesajı ve ona bağlı tool mesajları her zaman kalır.
3. Ollama çağrısı: `POST http://127.0.0.1:11434/api/chat`, `model:
   qwen2.5:14b`, `stream: true`, `options: {"temperature": 0.2}`, `tools`.
   `httpx.AsyncClient`, karar zaman aşımı 10 sn, genel 30 sn. Ollama adresi
   ve model adı modül sabiti (env ile ezilebilir: `FARABI_SES_OLLAMA`,
   `FARABI_SES_MODEL`) — taşınabilirlik.
4. Stream'de `content` gelirse doğrudan istemciye aktar (cümleleme ses
   düğümünün TTS katmanında). `tool_calls` gelirse:
   - Birden fazlaysa YALNIZCA ilki (log'a uyarı). Turda tek araç.
   - **`kitap_sorusu`**: hemen `"Kitaba bakıyorum. "` gönder. Kitap:
     `ders` = araç argümanı ya da `metadata.ders`; ikisi de yoksa eşleştirme
     YAPMA, `"Hangi dersin kitabına bakayım?"` de. Kitap listesi DB `kitap`
     tablosundan (`main.py::kitaplar` ile aynı sorgu), eşleştirme
     `icerik._ders_eslesir` + sınıf düzeyi (client `kitap_sorusu._kitap_id_bul`
     mantığı). Soru metni: **kullanıcının son mesajı** (model argümanındaki
     `soru` değil — qwen "ı"→"i" bozabiliyor). `durum["motor"].sorgula(conn,
     kitap_id, soru, sinif=, ders=)` `run_in_threadpool` içinde; DB bağlantısı
     (`db.baglanti()`) YALNIZCA bu çağrı süresince. Sonuç:
     - `ok` → cevap + `" Kaynak: {sinif}. Sınıf {ders}, sayfa {s1, s2}."`
       (sayfalar tekrarsız, sıralı; "s." değil "sayfa" — TTS). İKİNCİ LLM
       TURU YOK, aynen aktarılır.
     - `yetersiz_kaynak` / `sayi_kontrolu_reddi` → `"Bu bilgi ders kitabında
       bu haliyle bulunmuyor."`
     - `hata` / istisna → `"Şu an kitaba ulaşamıyorum."`
     - `durum["hazir"]` False → aynı `"Şu an kitaba ulaşamıyorum."`
   - **`ders_icerigi`**: `"Konuyu açıyorum. "` gönder; `icerik.ders_icerigi_endpoint(
     KonuIstek(..., derslik=derslik))` threadpool'da (derslik ŞART —
     `_SON_KITAP` senkronu, `pdf_sayfa` aynı kitabı açsın). `metin` ≤ 6000
     karakter (endpoint'in kendi `MAX_KARAKTER`'i) → `tool` mesajı olarak
     eklenip Ollama'ya İKİNCİ çağrı (araçsız), çıktısı stream edilir.
     `status != "ok"` → `"Bu konuyu kitapta bulamadım."`
   - **Tahta araçları** (`pdf_sayfa`, `yks_sorulari`, `pencere_kapat`):
     OpenAI biçiminde `tool_calls` delta'sı (`id: call_<uuid8>`, `type:
     function`, `arguments` JSON string) + `finish_reason: "tool_calls"`.
     Ses düğümü aracı tahtada çalıştırıp sonucu `tool` mesajıyla yeni istekte
     gönderir; o istekte döngü 1. adımdan devam eder.
   - Kipte kapalı ya da bilinmeyen araç adı → yok say, `"Bunu şu an
     yapamıyorum."`
5. **Boş cevap** (içerik de araç da yok): aynı mesajlarla BİR kez yeniden
   dene; yine boşsa `"Anlayamadım, tekrar eder misiniz?"`.
6. **Hata/zaman aşımı:** stream başladıktan sonra hiçbir istisna 500'e
   dönmez — `"Şu an yanıt veremiyorum."` içeriği + `finish_reason: "stop"` +
   `[DONE]`. Stream başlamadan önceki erişim hataları normal HTTP kodları.
7. `stream: false` → aynı mantık, tek `chat.completion` JSON (`message.content`
   ya da `message.tool_calls`, `finish_reason`).

SSE biçimi (OpenAI ile birebir): her olay `data: <json>\n\n`, `object:
"chat.completion.chunk"`, `id: "chatcmpl-<uuid>"` (istek boyunca sabit),
`created`, `model: "farabi-brain"`, `choices[0].delta` ilk olayda `role:
"assistant"`, son olayda `finish_reason`, en sonda `data: [DONE]\n\n`.
`media_type="text/event-stream"`.

Loglama (journal, içerik yok): derslik, kip, seçilen araç, karar ms, toplam
ms, sonuç türü.
